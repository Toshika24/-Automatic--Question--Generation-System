# Automatic Question Generation System

## Requirements
- Python 3.9 or newer
- Streamlit
- NLTK

## Installation

Open Command Prompt in this folder and run:

pip install -r requirements.txt

## Run

streamlit run app.py

The browser will open the dashboard automatically.

## How it works

Study Material
-> Text Preprocessing
-> Sentence Tokenization
-> POS Tagging / Named Entity Recognition
-> Important Word Detection
-> Rule-Based Question Templates
-> Generated Questions

## Demo input

Machine Learning is a branch of Artificial Intelligence. It allows computers to learn from data without being explicitly programmed. Machine Learning is used for prediction and classification.

## Note

This is a simple rule-based NLP mini-project designed for an academic demonstration. It is not a large language model.
